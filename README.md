# Formula 1 Race Analytics — WIP Workbench

Exploratory Formula 1 analytics work around race results, driver performance, pit stops, qualifying, and Power BI modelling.

> **Note:** The polished public-facing pipeline repository is [Formula 1 Analytics](https://github.com/eswarsurya/formula1-analytics). This repository is kept as an experimental workbench for ongoing ideas and dashboard development.

## Focus

- FastF1 data refresh workflows
- Race and driver analysis
- Power BI data-model experiments
- Output validation and dashboard planning
- Testing ideas before moving stable work into the main project

## Tools

Python · FastF1 · Pandas · Power BI · CSV data modelling

## Project status

**Experimental / Work in progress**

I keep unfinished experiments here so the main project can remain focused and reviewable while development continues.
